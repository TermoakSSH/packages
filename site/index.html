termoak is the desktop app (command termoak-desktop), termoak-cli the command-line client (termoak) and termoak-server the self-hosted server with its systemd units. They need glibc 2.34 or newer (2.35 for the desktop app): Debian 12+, Ubuntu 22.04+, Fedora, RHEL/Alma/Rocky 9+ (server and CLI), openSUSE Tumbleweed and Leap 16, Arch Linux.

termoak es la app de escritorio (comando termoak-desktop), termoak-cli el cliente de línea de comandos (termoak) y termoak-server el servidor autoalojado con sus unidades de systemd. Necesitan glibc 2.34 o más reciente (2.35 para el escritorio): Debian 12+, Ubuntu 22.04+, Fedora, RHEL/Alma/Rocky 9+ (servidor y CLI), openSUSE Tumbleweed y Leap 16, Arch Linux.

Debian, Ubuntu, Linux Mint, Pop!_OS, Raspberry Pi OS (64-bit)

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://pkg.termoak.com/termoak.gpg | sudo tee /usr/share/keyrings/termoak.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/termoak.sources >/dev/null <<'EOF'
Types: deb
URIs: https://pkg.termoak.com/deb
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/termoak.gpg
EOF
sudo apt update
sudo apt install termoak          # desktop
sudo apt install termoak-cli      # CLI
sudo apt install termoak-server   # server

openSUSE Tumbleweed, Leap 16

sudo rpm --import https://pkg.termoak.com/termoak.asc
sudo zypper addrepo --refresh https://pkg.termoak.com/rpm/termoak.repo
sudo zypper refresh
sudo zypper install termoak termoak-cli termoak-server

Arch Linux, Manjaro, EndeavourOS

curl -fsSL -o /tmp/termoak.asc https://pkg.termoak.com/termoak.asc
sudo pacman-key --add /tmp/termoak.asc
sudo pacman-key --lsign-key @FINGERPRINT@
sudo tee -a /etc/pacman.conf >/dev/null <<'EOF'

[termoak]
SigLevel = Required DatabaseRequired
Server = https://pkg.termoak.com/arch/$arch
EOF
sudo pacman -Sy termoak termoak-cli termoak-server

Packages for x86_64; termoak-cli and termoak-server also for aarch64 (Arch Linux ARM). The desktop app needs a Vulkan driver (vulkan-radeon, vulkan-intel, nvidia-utils or, without a GPU, vulkan-swrast) and a font such as ttf-dejavu.

Paquetes para x86_64; termoak-cli y termoak-server también para aarch64 (Arch Linux ARM). La app de escritorio necesita un driver Vulkan (vulkan-radeon, vulkan-intel, nvidia-utils o, sin GPU, vulkan-swrast) y una fuente como ttf-dejavu.

After installing the server

Después de instalar el servidor

The package creates the termoak system user, /etc/termoak/config.toml and /var/lib/termoak, but does not start anything. Review the configuration and then:

El paquete crea el usuario de sistema termoak, /etc/termoak/config.toml y /var/lib/termoak, pero no arranca nada. Revisa la configuración y después:

sudo systemctl enable --now termoak-sessions termoak-server
